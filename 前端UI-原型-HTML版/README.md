# 梧桐校园 · V2 视觉升级版 HTML 原型

根据原项目的 README、学生端和管理端路由、页面表单、API 封装及图片素材制作。原项目文件只读，本文件夹为独立交付件。

本次版本重点是审美与排版重设计，使用 Anthropic `frontend-design` 技能规划并审视设计。与 V1 相比，学生端改为顶部导航，采用蓝白视觉与新生成的校园摄影；活动封面改成 HTML / SVG，详情页引入报名通行证布局，AI 学习页、登录页和管理工作台重新构图。V1 ZIP 单独存档，不属于本次新版包。

**建议先双击 `交付导航.html`**：可以查看代表页面、前后对照，并进入实际交互。

## 打开方式

1. 双击 `index.html` 查看学生端。
2. 双击 `admin.html` 查看管理端，或从学生端页脚切换。
3. 点击页脚“页面导航”，查看全部入口。

不需要安装 Node.js、Vue、数据库或后端。全部样式、脚本、图片均为本地相对路径，不引用 CDN，不发送网络请求。复制整个文件夹到其他位置后仍可打开。请勿只复制 HTML 而遗漏 `assets`。

推荐使用 Edge、Chrome 或其他现代浏览器。浏览器对 `file://` 下本地存储的处理不同：单页操作可正常演示，但学生端与管理端的数据共享不保证。若需跨端联动，可在本文件夹启动可选的静态服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8765/index.html`。这仅提供静态文件，不是项目后端。

## 演示注意

所有用户、统计数字与交互记录均为演示数据。日期固定在 2026 年秋季。新版校园主视觉为 AI 生成的虚构摄影，物品及校园生活图片沿用原项目素材；活动封面由 HTML / SVG 重新设计。

- 不验证真实账号。登录页输入任意 6 位以上密码，并正确填写页面运算验证码即可；注册还需两次密码一致。
- 管理员登录可选择“超级管理员”或“内容管理员”；后者看不到系统管理菜单。此限制仅为 UI 演示，不是安全鉴权。
- 活动、预约、认领页面提供“模拟审核”按钮，用于单独演示闭环，正式实现应由发布者操作。
- AI 回复、代码分析、失物匹配、复习计划均为预设或本地逻辑；未连接真实模型。PDF/OCR 仅展示上传入口与文件预览，不执行识别或解析。
- 图片选择仅用于当前表单预览，提交记录使用内置示例封面。原型不上传文件。
- 修改密码仅校验表单，不保存密码；AI 配置也不保存 API Key。
- 操作保存在浏览器 `localStorage` 的 `wutong-prototype-v1` 项下；可通过页脚“重置演示”恢复。
- 源项目含更多生产能力，原型不等于完整功能实现；具体边界见 `docs/页面与交互说明.md`。

## 文件结构

```text
index.html                 学生端入口
admin.html                 管理端入口
交付导航.html               新版预览、代表页面、V1 / V2 对照
assets/style.css           设计变量、布局、组件、响应式、主题
assets/data.js             虚构示例数据
assets/app.js              业务演示、路由、通用页面与事件
assets/design-v2.js        V2 页面构图与视觉组件，覆盖对应旧视图
assets/images/             本地图片（包含新生成的校园主视觉）
docs/                      交接资料
qa/                        浏览器验证脚本、报告和截图
qa/v2/                     V2 多尺寸视觉验收截图、前后对照与报告
```

`qa/verify.cjs` 使用 Playwright + Edge 进行开发验证，不是运行原型的依赖。测试在独立浏览器上下文中执行，不会污染日常浏览器的演示状态。

`qa/visual-v2.cjs` 补充检查 1440 / 1024 / 820 / 768 / 390 / 360px 六种视口、外部资源请求和代表页面截图。实际记录见 `qa/v2/visual-report.json`。
