## 验证边界

原脚本真实检查了注册/登录/退出及权限隔离、审核通过/驳回、预约状态与互评、活动报名与签到、认领、搭子、问答、动态、公告、通知、收藏、举报、私信历史/已读、图片上传与文件拦截、搜索筛选分页、3D 进入服务与手动打开/返回/全屏、桌面手机渲染及并发预约的最终状态。许多业务操作通过真实 HTTP API 验证，页面截图只证明渲染，不能解释为每个功能按钮都完成了真实 UI 操作。

唯一 UNCOVERED 是“AI 限额/未配置错误提示”。其原脚本固定备注写了“正常路径已在类别15验证”，但本轮明确跳过类别15，因此该句不适用于本轮，不能据此声称 AI 成功路径通过。成功 AI 流式响应、真实 OCR 和多用户 WebSocket 推送仍未覆盖；私信类别验证的是真实接口和持久化历史。

隔离环境按照原 `docker-compose.e2e.yml` 关闭验证码校验，测试中没有更改生产/主项目配置。真实验证码安全校验不属于本轮 E2E 成功结论。
