# 管理端审核卡片排版修正

2026-09-29，沿用 `feat/tongpin-ui-redesign` 分支。

## 问题与原因

闲置审核的缩略图与正文重叠，AI 预审说明在宽屏上过长，审核按钮垂直居中而脱离标题。

浏览器在真实 Docker 页面复现：新版网格第一列为 120px，旧 `.review-cover` 仍固定为 148px；加上 20px 列间距，正文左侧比封面右侧提前 8px。只在浏览器临时将封面宽度改为网格的 100%，间距就恢复为 20px，验证了尺寸冲突。原浏览器验收仅检测页面溢出，没有检测卡片内部的元素重叠，因此漏掉此问题。

## 修改范围

只修改 `web/frontend/admin/src/views/audit/AuditModule.vue` 的 scoped CSS。其共享页面包括活动、闲置、失物招领、动态和搭子审核。

- 桌面封面列设为 148px，封面宽度跟随所在列；图片组件填满封面，保持裁切与预览功能。
- 图片与正文留出 24px 间距；中等屏幕使用 100px 封面列，封面同步缩小。
- 桌面审核按钮与正文顶部对齐；较窄屏幕操作区独占一行，手机保持纵向卡片。
- AI 预审说明限制在 760px 阅读宽度内，并减少内边距。说明全文仍按内容自然换行。
- 标题可使用正文的完整宽度，自然换行；搭子审核继续使用没有封面的布局。

模板、脚本、接口、权限、业务条件及处理函数均未修改。
