# 搜索结果图片与行高修正

2026-09-29，用户反馈搜索结果没有显示图片。沿用 `feat/tongpin-ui-redesign` 分支。

## 原因及真实数据

搜索页面调用原有活动、闲置、失物招领、动态列表接口，但映射结果时仅保留标题、摘要、链接等字段，丢弃了图片信息；结果模板也没有图片节点。因此即使接口有图，搜索页仍然只显示文字。

另有重复样式及残留的 `\3c style scoped>`。结果按钮原先沿用纵向 flex 排列，后续给标题设置 `flex: 1 1 240px`，造成短标题也占用很大垂直空间。

隔离环境真实“数学”查询有两条闲置结果：

- ID 10“考研数学资料包”：`images` 为空、`imageList` 为空，其旧分类“教辅”也没有现有回退图，必须显示“暂无图片”。
- ID 1“高等数学第七版上册”：接口有 `imageList`，首张为原有 Data URI 图片，应显示该图片。本次不更换数据库中的图片内容。

修正前浏览器检查按预期失败：接口有 1 张图片，搜索页图片节点数为 0。

## 修改内容与功能边界

- `web/frontend/student/src/views/search/SearchResults.vue`：新增缩略图和标题/摘要容器，整理 scoped CSS。桌面采用 112×84px 缩略图，手机采用 80×72px 缩略图；文本允许换行，不再使用纵向 240px 的 flex 基准。
- 同文件脚本仅新增 `SearchResultCover` import，并在原有四条结果映射中各新增 `media: item`，将接口已有记录交给图片展示组件。没有新增请求或改写记录。
- 新增 `web/frontend/student/src/components/wt/SearchResultCover.vue`：复用原 `content-assets.mjs` 图片规则，兼容 `imageList`、JSON 字符串图片和 Data URI。动态模块的展示名称 `post` 对应现有 `social` 回退图。回退图标记“示意图”；未知类别无图显示占位；加载失败先尝试现有回退图，回退图再次失败后显示占位。
- 原四个列表 API、keyword/pageNum/pageSize 参数、分类及计数、加载状态、空结果提示、关键词安全转义及高亮、查看全部携带关键词、详情/动态跳转全部保留。没有修改后端、数据库、API 文件、权限守卫、状态管理、图片工具或已有测试。

这是后续图片显示缺陷的专项修正，必须将已有图片字段传给展示层，涉及上述准确限定的 Vue 脚本增加。原冻结审计和基准不做修改，也不把审计的例外描述成全通过。

- 另有 2 次交互准备测量，共 30 次测量；4 个分类筛选、动态查询链接、查看全部携带关键词，共 6 次原有交互检查通过。浏览器运行时错误 0。

先前 `verify-route-scroll-compatibility.mjs` 严格限定当时的两个差异，本次不放宽该历史验证器；当前整体使用包含精确搜索展示增加的验证器。
