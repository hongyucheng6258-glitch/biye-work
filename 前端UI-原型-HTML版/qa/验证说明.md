## 复跑验证

`verify.cjs` 需要 Node.js、Playwright 和已安装的 Microsoft Edge。若当前环境已安装 Playwright，可执行：

```powershell
node qa/verify.cjs
node qa/visual-v2.cjs
node qa/delivery-check.cjs
```

若 Playwright 安装在其他目录，通过 `NODE_PATH` 指向对应 `node_modules`。测试只改变独立浏览器上下文内的数据并重新生成本目录报告/截图，不修改源项目。
