# 学生端登录与注册背景设计

## 状态

设计方向已由用户确认，本文档等待用户评审。评审通过后再制定实施计划并修改页面。

## 目标

- 让学生端登录页和注册页共享一致、温暖的校园视觉。
- 以校园实景照片作为主要背景，同时保持表单文字和输入区域清晰。
- 适配桌面和手机，不改变现有认证流程。

## 当前情况

登录页和注册页目前各自实现了相似的左右分栏布局：左边放品牌文案和一张校园图，右边放表单。项目已有本地图片 `web/frontend/student/public/images/campus-v2.webp`，无需新增外部图片或网络依赖。两页样式分别写在各自的 Vue 页面中。

## 考虑过的方案

1. **左右分区，采用此方案。** 左侧用校园实景和柔和蓝色光影承载品牌故事；右侧用浅色背景承载表单。它保留清晰分区，能容纳较长的注册表单。
2. **整页照片，表单浮在中间。** 氛围更沉浸，但表单会遮挡较多画面，长注册表单也更难排布。
3. **全页虚化校园照片。** 视觉安静，但校园场景会变得不明显，登录和注册页的辨识度较弱。

## 选定设计

### 桌面布局

保留左右分栏，左侧约占页面宽度的 54%，右侧约占 46%。左侧以 `campus-v2.webp` 铺满，使用深蓝到透明的渐层柔化照片局部亮度；品牌标志、欢迎语和简短校园文案置于照片上方。照片裁切时优先保留教学楼和梧桐树。

右侧使用云白底色，在边缘加入低对比度的校园蓝与叶绿色柔光。表单保持约 400px 的阅读宽度并垂直居中，不额外叠加厚重装饰；屏幕高度不足时，右侧区域可以滚动，确保注册页字段和提交按钮可达。

### 手机布局

窄屏时将照片区收成约 120px 高的顶部横幅，只保留品牌标志和简短欢迎语。表单位于其下方的浅色页面上，页面自然纵向滚动；照片不铺在输入框背后。

### 色彩

延续项目现有蓝白校园体系，颜色用于光影和遮罩，不改变按钮、验证码或表单状态色：

| 用途 | 色值 |
| --- | --- |
| 深校园蓝遮罩 | `#18365B` |
| 品牌校园蓝 | `#315BB8` |
| 云白表单底色 | `#F4F7FB` |
| 梧桐叶柔绿 | `#B6D5C6` |
| 阳光暖金 | `#F0D9A2` |

字体继续使用项目的中文优先无衬线字体和现有字阶，不添加新的字体文件。

## 范围与边界

- 只调整学生端登录和注册页面的背景、两页共用的视觉规则及响应式呈现。
- 登录、注册、验证码、表单校验、跳转及接口行为保持不变。
- 不改管理端登录页面，也不新增外部图片、字体或运行时依赖。
- 背景照片作为装饰处理；文字与表单仍提供完整的可访问名称和键盘焦点样式。

## 验收标准

1. 登录和注册页使用同一张校园主图、相同的蓝色光影与底色体系。
2. 桌面端照片覆盖左侧视觉区，右侧表单对比清楚；较短屏幕可滚动到注册页提交按钮。
3. 手机端显示紧凑照片横幅，表单不叠在照片上，页面可纵向滚动。
4. 验证码、表单控件、提示信息与当前认证操作保持原有行为。
5. 页面使用本地已有图片，无新增网络请求或第三方依赖。

## 实施后的检查

实施时检查桌面和手机宽度下的登录、注册两页；确认图片裁切、文字对比、焦点状态和长注册表单滚动体验。此项检查在设计评审通过并实施后进行。
