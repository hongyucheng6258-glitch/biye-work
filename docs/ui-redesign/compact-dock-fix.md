# 悬浮导航减小遮挡

2026-09-29，用户反馈底部悬浮导航遮挡视野，沿用已实施的无侧边栏设计和 `feat/tongpin-ui-redesign` 分支。

## 问题与调整

真实浏览器测得原桌面导航宽 560px、高 66px，下方间距 20px；使用 `--shadow-lg` 的 60px 模糊阴影又扩大了视觉干扰范围。手机原导航高 60px、下方间距 12px。

本次采用紧凑导航，保留现有位置和六个入口。仅调整 `web/frontend/student/src/layout/MainLayout.vue` 中 `.tp-dock` 及其子元素 scoped CSS：

- 桌面最大宽度 560→432px，导航高度 66→54px，本体矩形面积减少约 37%。距底部 20→8px。
- 手机导航高度 60→54px，距底部 12→6px；视口两侧各留至少 8px。
- 外层 padding 8→4px、间距 6→2px；按钮始终至少高 44px，320px 视口下按钮宽度也超过 44px。
- 原大范围阴影改为 `0 4px 14px` 的淡阴影；移除模糊背板，背景复用主题的 surface 色。
- 保留当前分类高亮和“全部”强调，增加明确的键盘焦点轮廓。
- 保留底部安全区 `env(safe-area-inset-bottom)` 和原页脚底部留白；没有隐藏或自动收起入口。

固定导航仍会覆盖视口最下方的一小条内容。本次减小其遮挡范围，并确认滚到文档末尾时页脚链接可完整显示；不声称浮层在任意滚动位置都完全不叠加内容。移动设备安全区通过原 CSS 计算保留，浏览器尺寸检查未模拟实体设备的系统键盘。
