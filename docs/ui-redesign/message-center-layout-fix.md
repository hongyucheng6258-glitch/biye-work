# 消息中心排版修正

2026-09-29，沿用 `feat/tongpin-ui-redesign` 分支及原改版提示词中消息中心的布局要求。

## 问题与原因

消息分类竖排居中、重复标题占据额外空间，列表存在多层大卡片，消息图标、正文和时间未正确对齐。

在真实 Docker 学生端复现：`.msg-sidebar` 仍继承旧样式 `flex-direction: column`，后加的横向布局没有覆盖它。1440px 视口下分类区域高 342.30px。仅在浏览器覆盖为 `row`，就能恢复横向排列，确认根因。

样式中还残留了 `\3c style scoped>` 文本，使原 `.msg-item` 选择器无法匹配，消息行原本的 flex 排版失效。此前验收主要检查整体横向溢出，未检查分类方向与行内排列，因此漏掉此问题。

## 修正

只整理 `web/frontend/student/src/views/message/MessageCenter.vue` 的 scoped CSS，模板与脚本完整保留。

- 分类变为一排胶囊按钮，私信入口在桌面靠右；手机自然换行，全部五个入口始终显示。
- 分类栏高缩至约 73.45px；重复静态标题改为辅助技术可读的隐藏标签，页面主标题继续显示。
- 消息区域使用一个完整容器，取消列表内部嵌套的大边框。
- 图标、正文、时间形成清楚的消息行；手机的时间移到正文下方。
- 未读消息使用浅绿背景、深绿边线和原未读点；已读消息更轻，明暗主题均使用现有设计变量。
- 标题及正文自然换行，长链接不会撑破卡片；保留原加载、空态与分页。
- 保持原焦点样式；减少动效设置下关闭本页新增的悬停过渡。

全部/system/interact/audit 分类、未读徽标、私信未读数、全部已读、单条已读、关联业务跳转、分页及所有绑定均未修改。
