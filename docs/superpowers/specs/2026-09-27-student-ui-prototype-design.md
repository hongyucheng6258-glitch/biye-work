# 学生端 UI 原型设计说明

## 目标

制作一份可本地打开、可交互浏览的学生端独立 HTML 原型，梳理梧桐校园学生端的视觉层级与主要页面体验。该原型用于视觉评审，不替换正式 Vue 页面，也不调用后端接口或修改业务数据。

## 项目背景

学生端目前采用 V2 校园蓝与云白的视觉体系，包含校园门户、活动与社区服务、AI 学习、消息和个人中心等功能。仓库已有旧版 HTML 原型，其配色和正式 V2 界面不一致。本次新增独立原型文件，沿用正式学生端的模块和本地素材，避免改动旧原型及当前页面。

## 范围

新增 `ui-prototype/student-refresh.html`。文件内包含样式和少量原生 JavaScript，可直接在本机浏览器打开。校园照片从 `web/frontend/student/public/images/` 使用相对路径加载；不引入外部图片、CDN、框架或接口。

原型以共享学生端应用外壳和可切换模块组成，覆盖以下主要页面：

- 门户首页、校园 3D 服务空间示意、搜索结果。
- 活动、闲置互换、失物招领、学习搭子、互助问答、动态广场、你画我猜、校园公告。
- 消息中心与私信会话。
- AI 答疑、代码纠错、错题本。
- 个人中心与公开个人主页。
- 登录、注册和维护提示页。

活动、闲置、失物招领、搭子、问答、公告、聊天和你画我猜模块提供相应的详情、发布或房间演示状态。游戏房间与 3D 校园以二维视觉示意呈现，不模拟真实多人连接或 WebGL 场景。

## 信息架构与交互

- 桌面端使用可收起的左侧分组导航、顶部全局操作栏和主内容区；移动端使用导航抽屉与单列布局。
- 首页突出校园摄影、近期活动和常用服务入口；其他模块按其任务选择列表、内容流、聊天、学习面板或个人资料布局，避免统一堆叠相同卡片。
- 导航切换、搜索、筛选、主题切换、登录/注册切换、发布弹窗和示例消息可交互。
- 表单使用本地校验；操作只改变原型中的示例状态，不持久化账号、消息或业务内容。
- 明确标示空内容和操作结果。键盘焦点可见，并尊重减少动效偏好。

## 视觉系统

- 云白底 `#F5F8FD`、纯白 `#FFFFFF` 用于页面与内容表面。
- 墨蓝字 `#24324C` 用于标题与正文；梧桐蓝 `#4267DC` 用于导航和主要操作。
- 杏阳色 `#F0D7B3` 用于少量活动强调；新叶绿 `#DDECE3` 用于社区与互助内容。
- 中文使用系统无衬线字体栈，以稳定字阶和字重区分标题、正文与辅助信息。
- 首页和登录/注册页使用仓库内校园照片；图片之外保持克制，避免每个模块使用同一色块、圆角和阴影组合。

## 响应式布局

- 桌面宽屏保留固定内容边界和清楚的导航/正文对齐关系。
- 平板窄屏收紧边距与栏目数量，避免横向溢出。
- 手机屏幕将双栏内容改为单列，导航改为抽屉，点击区域保持易操作。

## 验收标准

1. 单个 HTML 文件可离线打开；引用的项目本地图片正常显示。
2. 所有列出的主要模块都可从原型导航切换，重点子状态能从页面操作进入并返回。
3. 搜索、筛选、主题、发布弹窗、登录/注册切换与表单校验均有可见反馈。
4. 桌面和手机宽度均可浏览，无明显遮挡或横向溢出；键盘焦点清晰。
5. 不修改正式 Vue 前端、API、数据库、旧原型或依赖清单。

## 本次不包含

不接入真实认证、业务 API、WebSocket、持久化存储、真实 AI 调用、多人游戏逻辑或 3D 渲染。评审通过后，原型才作为视觉参考进入后续正式界面实施计划。
